# Unit 0 — Introduction

**Source:** https://huggingface.co/learn/deep-rl-course/unit0/introduction

## Learning objectives

- Understand course structure (theory + Colab + challenges).
- Choose certification path (80% / 100% / audit).
- Set up HF account, Colab, Discord (HF-specific).

## What students learn

| Topic | Detail |
|-------|--------|
| Course scope | Theory and practice from beginner to SOTA overview |
| Pacing | ~1 unit/week, ~3–4 h/week recommended |
| Tools | Colab + HF Hub + Discord community |
| Challenges | Leaderboard + AI-vs-AI (mostly deprecated) |
| Maintenance | Unit 7 competitions and leaderboard shut down; theory still valid |

Stable-Baselines3, RL Baselines3 Zoo, Sample Factory, CleanRL.

- Optional author sidebar: “Similar free courses exist (HF Deep RL); this course uses Godot instead of Colab Atari/Unity.”
